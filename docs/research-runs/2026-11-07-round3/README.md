## 3. NFI X8（`NostalgiaForInfinityX8Capped`，默认 3 倍、封顶 5 倍）

5m，20 个币，2024-11-07 ~ 2026-11-07：

| | 收益 | 交易 | 胜率 | 盈亏因子 | 回撤（含浮亏） | 回撤（只看平仓） |
|---|---|---|---|---|---|---|
| 训练段 2024-11-07 ~ 2026-03-08 | +470.75% | 171 | - | 15.44 | **30.26%（超过 15%）** | - |
| 样本外 2026-03-09 ~ 2026-11-07 | +54.27% | 35 | 97.14% | 23.45 | 9.28% | 1.92% |
| 走步 2 折拼接 | +75.66% | 56 | - | 18.52 | 9.28% | - |

结论是"未通过"（训练段回撤 30.26% 超过 15%），而且样本外的好成绩有两个大问号：

1. **整个测试区间对 NFI 作者来说都是样本内。** NFI X8 这个文件 2026-09-06 才建，按 GitHub 上的提交记录搜索，到 2026-11-07 已经提交了约 **1223** 次，
   其中 **488** 次的标题是 "add protection"。作者一直在用最近几年的行情改它，所以 2024-11 ~ 2026-11 这段（包括我们的"样本外"）
   作者都看过，不是独立证据。
2. **它拿着亏损的仓位不平。** 样本外只看平仓的回撤只有 **1.92%**，含浮亏是 **9.28%**；训练段含浮亏到了 **30.26%**。
   胜率 97% 是因为亏的仓位一直拿着，等反弹或者加仓摊平。所以只能看账户权益（已平仓余额 + 持仓浮动盈亏）。

另外一点：这一轮的回撤检查对加仓 / 分批平仓的交易用的是旧算法（按每笔交易**最后的**数量和均价套整个持仓期间），对 NFI 只是近似值。
第 4 轮起按逐笔订单重建持仓（`scripts/check_drawdown.py`，见 `docs/benchmarks.md` 第 7 节）。这里的原始报告保持原样；
想看新算法的数字，不用重跑回测，在 VPS 上对原来的结果目录重新生成报告就行（会覆盖那个目录里的报告文件，想留旧版先复制一份）：
`.venv/bin/python scripts/research_report.py report --run-dir <第 3 轮 5m 组的结果目录>`。

## 4. 第 4 轮做什么

计划（已经跟你说过、你同意的）：不再改 NFI，而是**冻结固定版本、降杠杆、先逐年回测做合理性检查、再上币安模拟盘做真正的样本外检验**。

1. **冻结**：NFI 固定在 commit `74c03087b8ced3899509ba8d36f5f1565bc5f49a`（`scripts/fetch_benchmarks.sh` 下载并核对 sha256），不跟着上游更新。
2. **低杠杆版本**：`NostalgiaForInfinityX8Lev1`（每一条杠杆路径都封顶 1 倍）、`NostalgiaForInfinityX8Lev2`（2 倍），
   和 5 倍封顶的 `NostalgiaForInfinityX8Capped` 一起放在 `user_data/strategies/benchmarks/BenchmarkCaps.py`。
3. **逐年回测**（在美国 VPS 上，OKX 5m 数据）：2021 ~ 2026 每个日历年单独回测一次（每次从 1000 USDT 开始，包含 2022 年熊市），
   币的个数按内存自动定；每个版本给一个"可以上模拟盘 / 不建议上模拟盘"的结论：`make research-nfi-yearly`，说明见
   [`docs/nfi-yearly.md`](../../nfi-yearly.md)。这些年份作者都可能看过，"可以上模拟盘"只是合理性检查。
4. **回撤算法**：加仓 / 分批平仓的交易按逐笔订单重建持仓（上面第 3 节最后一段）。
5. **币安合约模拟盘（前向测试）2 ~ 3 个月**：冻结版 NFI、1 倍杠杆，在**币安允许访问的地区**的服务器上跑（你那台跑 Rust 引擎的 Vultr 服务器）；
   美国 VPS 继续只做 OKX 回测。配**前向报告**和**账户权益看门狗**：含浮亏回撤超过 15% 就停止开新仓，等人工检查。
   `make dryrun-nfi-check` → `make dryrun-nfi`（长期用 systemd），说明见 [`docs/forward-test.md`](../../forward-test.md) 和
   [`docs/forward-monitoring.md`](../../forward-monitoring.md)。2026-11 以后的行情作者也没见过，这才是真正的样本外。
