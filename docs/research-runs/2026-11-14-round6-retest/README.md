   BollingerBreakout +22.6%、+3.7%、+20.6%、-3.2%、+0.4%、-4.2%；
   ChandelierBreakout -0.1%、-0.8%、+8.8%、+2.8%、+8.4%、-0.7%。
   2020 留出段三个都赚钱。也就是说：DualThrustTrend 和 BollingerBreakout 在 2020 ~ 2021、2023 的大行情里有效，最近两年在这批大币上没有优势，
   这和第 2、3 轮日线趋势策略"样本外接近打平"的结论一致。ChandelierBreakout 样本外单看是过的（+6.16%、PF 1.22），
   但每年都只有几个点，走步盈亏因子 1.09，去掉盈利最多的 3 天就亏（见下一条）。
2. **利润集中在很少的几天。** 没看过的一段里，盈利最多的 3 个入场日占 DualThrustTrend 利润的 79%、BollingerBreakout 的 77%
   （2021-01-04 一天就是 +349.6 USDT / +177.7 USDT）；ChandelierBreakout 去掉这 3 天以后是亏的（+7.95% → -6.56%）。
3. **初筛的样本外结果在 freqtrade 里没有复现。** 初筛（向量化）里 T21 样本外 +12.2%（PF 1.23）、T08 +24.1%（PF 1.35），
   按 0.4 倍仓位折算应当是小赚；freqtrade 逐笔回测是 -6.5% 和 -3.5%。这次没有逐笔明细，原因没有查证；
   两边已知的差别是：freqtrade 只有 8 个名额、先到先得（初筛是所有信号一起按比例缩小），有 25% 封顶的灾难止损和回撤降仓，
   币池 52 个（初筛 60 个）。不管是哪一个造成的，一个换了成交方式就从赚变亏的结果，本来就不可靠。
4. DualThrustTrend 仓位已经降到约 0.4 倍，2021 年回撤仍有 33.56%：那一年年初只有 13 个币能交易，账户权益先大涨（2021 全年 +50%）再回吐，
