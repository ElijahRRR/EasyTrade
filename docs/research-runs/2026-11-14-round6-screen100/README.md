## 结论：0 个通过

- 通过 0、边缘 0、像运气 0、未通过 100。没有一个策略连常规门槛（回撤 ≤ 15%、样本外 + 走步盈亏因子达标、手续费翻倍仍赚钱）都过了，
  多重检验还没用上就已经全部出局。
- 走步年化夏普的分布：平均 -0.16、中位数 0.00，48 个大于 0，7 个大于 0.5，最高 0.93（T21 Dual Thrust）。
  如果 100 个策略全都毫无优势，1080 天走步夏普的随机波动约 ±0.58，最好那个期望约 1.47。
  实际最好的 0.93 比"纯运气最好的"还低，整体分布和"没有优势"一致。
- 主要失败原因：回撤（单笔 1%、总风险约 6% 的仓位下，趋势类训练段 / 走步回撤普遍 30% ~ 50%）；
  均值回归类在 2021 ~ 2022 年训练段亏 70% ~ 90%；101 Alphas 日调仓手续费吃掉了几乎所有收益。
- 走步最好的几个（都没通过）：T21 Dual Thrust（走步 +94%、PF 1.59、回撤 22.5%，2022、2026 年亏）；
  T08 布林带突破（+73%、回撤 37%，和 T21 日收益相关 0.72，2021 一年贡献了大部分）；X04 低波动（+25%、训练段亏 23%）。
  T21 + T08 + X04 等权组合走步夏普 0.97、回撤 19%。这是看过结果以后挑的组合，不是证据。
