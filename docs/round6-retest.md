## 1. 放宽了什么、没放宽什么

- **放宽：不再要求多重检验**（Deflated Sharpe ≥ 0.95，大约要求走步年化夏普 ≥ 2.4）。这三个策略的走步夏普只有 0.36 ~ 0.93，
  连“100 个里纯靠运气最好的那个”（约 1.47）都没超过。去掉这一条，意思是**接受它们可能只是运气**，用后面的留出段和模拟盘来排除。
- **没放宽：账户回撤上限仍然是 15%（含浮亏）**。办法是把仓位降到初筛的约 0.4 倍，回撤大致同比例下降，收益也同比例下降。
  （David 如果要改成直接放宽回撤上限，在跑之前说，改这里和登记表。）
- 其他门槛和以前登记的策略一样：训练段、没看过的一段（2021 ~ 2023）、样本外、走步拼接，每一段都要
  赚钱、回撤 ≤ 15%、盈亏因子 ≥ 1.2、至少 30 笔；样本外盈亏因子不低于训练段的 0.6 倍。
- **2020 留出段**（2020-01-01 ~ 2020-12-31，这三个策略从来没用过）：交易 ≥ 30 笔时必须赚钱、回撤 ≤ 15%，否则失败。

## 2. 为什么是这三个

用初筛的正式结果重新筛：只看“除了回撤以外的门槛”（训练段赚钱、样本外和走步赚钱且盈亏因子 ≥ 1.2、≥ 30 笔、
样本外不明显退化、手续费翻倍走步仍赚钱），100 个里正好 3 个全过：

| 初筛编号 | freqtrade 类名 | 固定参数（初筛训练段选的） | 初筛走步：收益 / 夏普 / 盈亏因子 | 初筛最大回撤（三段里最大的） |
|---|---|---|---|---|
| T21 | `DualThrustTrend` | n = 10，k = 0.5 | +94.0% / 0.93 / 1.59 | 38.2% |
| T08 | `BollingerBreakout` | 50 日，2 倍标准差 | +72.9% / 0.71 / 1.39 | 37.1% |
| T29 | `ChandelierBreakout` | 50 日新高，3 × ATR22 | +20.8% / 0.36 / 1.23 | 41.4% |

仓位 ×0.4 以后，按比例估计回撤约 15% ~ 17%，走步收益约 +8% ~ +30%（3 年）。T29 很可能回撤仍然超标。

## 3. 必须说清楚的风险

1. **这三个是看完 100 个结果以后挑出来的。** 2021 ~ 2026 的数据上再用 freqtrade 跑一遍，只能回答
   “换成逐笔撮合、真实止损和仓位名额以后，结果还在不在”，**不算新的证据**。新证据只有 2020 留出段和以后的模拟盘。
2. T21 和 T08 都是突破类，初筛走步日收益相关系数 0.72；三个都是趋势跟踪，2022 年都亏。就算都通过，也只能算一类策略，
   不是三个互相独立的策略。组合检查（`make research` 自带）会按训练段相关系数 ≥ 0.7 只留一个。
3. 初筛的 60 个币是现在成交额靠前的，有幸存者偏差，对趋势做多偏乐观。
4. 仓位减到 0.4 倍以后，1000 USDT 账户里有些币的单笔金额可能低于交易所最小下单量，这些交易开不出来，
   freqtrade 的结果会和“初筛 × 0.4”有出入（报告里的交易数能看出来）。

## 4. freqtrade 版和初筛的对应

- 信号：和 `scripts/screen100/catalog.py` 里的 T21 / T08 / T29 逐条对应，持仓状态用同样的状态机算，参数固定、不调参（`--hyperopt 0`）。
- 仓位：初筛按波动率定仓、没有止损。freqtrade 版用 `easytrade_risk` 共用风控：灾难止损 = 5 × ATR20（最远 25%），
  每笔打到止损亏总资金 1% → 名义仓位 ≈ 1% / (5 × ATR%)，约等于初筛满仓位的 0.4 倍；组合热度 ≤ 6%；
  回撤到 8% 以后新仓减半；杠杆 ≤ 2；同时最多 8 笔（`configs/research-overrides/<类名>.json`）。
- 不一样的地方（也是这次复核要检验的）：名额满了以后的信号会被跳过（初筛是所有仓位一起按比例缩小）；
  有灾难止损和跳空处理；按 1h K 线模拟日线内部走势算回撤。
